AI Shorts Maker V2

Analisis adegan · narasi AI · ekspor MP4 bersuara

Versi ini membutuhkan backend lokal/hosting dan API key Gemini untuk analisis video. Pembuatan suara memakai edge-tts melalui internet. API gratis, kuota, dan ketentuan dapat berubah; penggunaan tidak dijamin selalu gratis.

1. Unggah video

Pilih video berdurasi lebih dari 1 menit. Disarankan MP4 dan ukuran di bawah 500 MB.

2. Analisis dan pilih gaya

Pilih video untuk mulai.

3. Klip dan narasi

AI akan mengusulkan rentang klip dan teks narasi. Kamu dapat mengedit narasi sebelum merender video.

Belum ada hasil analisis.

Petunjuk

Backend ini dirancang untuk berjalan di komputer atau server. Agar dapat diakses dari HP, host backend dengan HTTPS dan proteksi akses. Jangan mempublikasikan API key di HTML atau kode frontend.
